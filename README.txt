Proyecto: Automatizacion de solicitud de taxi - Urban routes
Se realiza la automatizacion del proceso de la solicitud de un taxi desde punto "A" a punto "B".
Lenguaje: Python
Paqueteria utilizada: Selenium 4.28.1,Pytest 8.3.4
Modelo de automatizacion: POM (Page Object Model)
Herramientas de desarrollo: Pycharm
